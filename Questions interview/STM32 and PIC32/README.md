PMCU-01 — DMA: Direct Memory Access

A practical reference covering DMA fundamentals for STM32 and PIC32 microcontrollers. It explains DMA architecture, channels and requests, memory/peripheral transfers, circular operation, interrupts, buffering, and practical configuration concepts. The document also includes technical and interview-oriented questions in French and English.

PMCU-02 — GPIO: General-Purpose Input/Output

A comprehensive guide to GPIO configuration and operation on STM32 and PIC32. Topics include input/output modes, pull-up and pull-down resistors, push-pull and open-drain outputs, alternate functions, electrical considerations, register-level concepts, interrupts, and practical hardware interfacing.

PMCU-03 — Interrupts

This volume focuses on MCU interrupt architecture and real-time event handling. It covers interrupt sources, vectors, priorities, masking, ISR design, latency, nested interrupts, external interrupts, peripheral interrupts, debugging techniques, and common implementation problems on STM32 and PIC32.

PMCU-04 — Timers & Counters

A detailed reference on one of the most important MCU peripheral families. It covers timer and counter architecture, prescalers, auto-reload/period configuration, overflow, interrupts, external counting, timing calculations, periodic events, frequency measurement, and practical STM32/PIC32 applications.

PMCU-05 — PWM, Capture & Compare

This part extends timer knowledge into practical signal generation and measurement. It covers PWM generation, frequency and duty-cycle calculations, output compare, input capture, pulse-width and frequency measurement, timer channels, synchronization concepts, interrupts, and real embedded applications.
